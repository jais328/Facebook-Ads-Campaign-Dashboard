## 📌 Overview
Interactive Power BI dashboard analyzing Facebook Ads 
campaign performance data across age groups, gender, 
and campaigns.

## ✅ Features
- 🖱️ Total Clicks — 38K
- 💸 Total Spent — $58.71K
- 🎯 Total Conversions — 3K
- ✅ Approved Conversions — 1K
- 📈 CTR — 1.79%
- 👆 Clicks by Age Group
- 👁️ Impressions by Age
- 🎯 Campaign Conversion Analysis
- 👥 Gender Split Analysis
- 💰 Ad Spend by Age Group
- 🔍 Dynamic Gender Filter

## 🛠️ Tools Used
- Power BI Desktop
- DAX Measures
- Facebook Ads Dataset (Kaggle)

- `Facebook_Ads_Dashboard.pbix` — Power BI file
- `KAG_conversion_data.csv` — Facebook Ads data
